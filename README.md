## ⚡ About Me

I am **Muhammad Usman**, a BS Physics student at **Bahauddin Zakariya University, Multan** with a deep passion for embedded systems and hardware engineering. I build projects that sit at the intersection of **physics, electronics, and software** — turning raw sensor data into meaningful human interaction.

## 🚀 Featured Projects

<details>
<summary><b>🎸 Air Guitar — ESP32 Motion-Controlled Virtual Instrument</b></summary>

<br>

> A wearable ESP32-based system that translates hand gestures and wrist motion into real-time guitar sounds — play music without touching an instrument.

<div align="center">

| Attribute | Detail |
|---|---|
| **Stack** | ESP32, MPU6050, C++, Arduino IDE, BLE / Serial Audio |
| **Hardware** | ESP32 DevKit, IMU sensor, flex resistors, 3.7V LiPo |
| **Gesture Engine** | Accelerometer + gyroscope fusion for strum & chord detection |
| **Output** | MIDI / tone generation mapped to detected gestures |
| **Status** | ✅ Working Prototype — Active Improvement Phase |
| **Repository** | [github.com/Usmanxbit](https://github.com/Usmanxbit) |

</div>

The Air Guitar project captures 6-axis IMU data from the MPU6050 mounted on the hand. Strum gestures are isolated via angular velocity thresholds on the gyroscope Z-axis, while chord shapes are mapped through accelerometer tilt vectors. The system outputs audio tones via PWM or streams MIDI over BLE to a host device. Currently improving chord discrimination accuracy and expanding the sound library.

<br>
</details>

<details>
<summary><b>🖐 Gesture-to-Speech Glove — Assistive Communication Device</b></summary>

<br>

> A smart glove that recognises hand gestures of people who cannot speak and converts them into real-time speech output — bridging the communication gap for the speech-impaired.

<div align="center">

| Attribute | Detail |
|---|---|
| **Stack** | ESP32, Flex Sensors, MPU6050, C++, TTS Engine |
| **Hardware** | Glove form-factor, 5× flex sensors, IMU, ESP32, speaker module |
| **Recognition** | Multi-sensor fusion — finger bend + wrist orientation |
| **Output** | Text display + audio speech synthesis |
| **Impact** | Assistive technology for speech-impaired individuals |
| **Status** | 🔧 In Development |
| **Repository** | [github.com/Usmanxbit](https://github.com/Usmanxbit) |

</div>

This project combines flex sensor readings (finger bend angles) with IMU orientation data to identify a predefined vocabulary of hand signs. Each recognised gesture triggers a mapped phrase that is rendered as speech through a TTS module or companion app. The goal is an affordable, portable, offline-capable device that empowers those who rely on sign language to communicate in everyday environments.
